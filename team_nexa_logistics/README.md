# TEAM NEXA Logistics Management System

A polished full-stack starter/demo for TEAM NEXA's multi-branch container availability,
allocation and tracking workflow.

## Included
- TEAM NEXA Owner login
- District-specific Branch Manager login
- Common Employee login
- Dashboard, container inventory, shipment requests, allocation approvals,
  tracking timeline, branches, reports and notifications
- Centralized simulated container database
- Responsive modern UI
- Role-based dashboard routing

## Run
This demo uses a lightweight Node/Express backend and a vanilla HTML/CSS/JS frontend.

Backend:
  cd backend
  npm install
  npm start

Then open:
  http://localhost:5000

The frontend is served by Express from ../frontend.
